# W6D1 模块1：Mel 频率尺度

## 1. Hz 与 Mel

Hz 描述什么：
Hz表示频率的物理单位，表示每秒振动或周期变化的次数。

Mel 描述什么：
Mel是根据人类音高感知特征构建的一种频率尺度。它用非线性的方式建立物理频率与感知尺度之间的近似对应关系。

为什么语音特征中需要 Mel 尺度：
线性Hz频率轴并不能直接体现人耳在不同频率区域的感知差异。Mel尺度可以用于构建非均匀分布的频带，使低频区域通常具有较密的频带分布，高频区域的频带间隔相对较大。

## 2. Mel 映射曲线

横轴：
实际频率，单位为 Hz。

纵轴：
对应的 Mel 数值。

为什么曲线不是直线：
在 HTK 定义下，Hz 与 Mel 之间是对数形式的非线性关系：
mel = 2595 × log10(1 + f/700)
随着频率增加，Mel 值继续增加，但增加速度逐渐减慢。

低频与高频区域的曲线斜率有何区别：
低频区域斜率较大，高频区域斜率较小。
因此，相同的 Hz 增量，在低频区域通常对应更大的 Mel 增量，在高频区域对应较小的 Mel 增量。

## 3. Mel 间隔

等 Hz 间隔表示什么：
相邻频率点之间的物理频率差相同，例如500 Hz、1000 Hz、1500 Hz。

等 Mel 间隔表示什么：
相邻频率点对应的 Mel 数值差相同。

为什么等 Mel 间隔对应的 Hz 间隔通常随频率升高而变大：
HTK 的反变换为：
f = 700 × (10^(mel/2595) - 1)
随着 Mel 增加，相同的 Mel 增量对应的 Hz 增量逐渐增大。
因此，等 Mel 间隔对应的 Hz 位置通常表现为低频密集、高频稀疏。

## 4. HTK 与 Slaney

HTK 公式：
mel = 2595 × log10(1 + f/700)
HTK 在整个非负频率范围采用对数形式的映射。

Slaney 尺度的主要特点：
librosa 实现的 Slaney 尺度采用分段定义：
- 1000 Hz 以下使用线性映射。
- 1000 Hz 及以上使用对数映射。
HTK 与 Slaney 对 Mel 数值的定义不同，因此不能直接将两者的输出视为同一尺度。

为什么不能直接与 librosa 的默认值逐点比较：
librosa.hz_to_mel()默认使用htk=False，即Slaney尺度，如果手写HTK公式，需要通过 librosa.hz_to_mel(frequencies, htk=True) 比较。

Mel 尺度约定与滤波器组归一化是否是同一件事：
不是。
Mel尺度约定决定Hz与Mel之间如何转换，从而影响滤波器的频率位置。滤波器组归一化决定滤波器权重如何缩放，例如是否进行面积归一化。在 librosa 的 Mel 滤波器组接口中，htk 与 norm 是两个不同参数。

## 5. 当前理解

- Mel 尺度为什么是非线性的：
它用于近似描述人耳音高感知与物理频率之间的非线性关系。

- 为什么高频区域的 Mel 间隔对应更大的 Hz 间隔：
由于 HTK 的反变换包含指数关系，相同 Mel 增量在高频区域对应更大的 Hz 增量。

- 为什么 Mel 尺度不是对原始语音直接做 FFT：
Mel 尺度本身只是频率坐标的映射规则，并不是计算频谱的算法。实际提取 Mel 功率特征时，通常先计算 STFT 功率谱，再通过 Mel 滤波器组对频谱进行加权汇总。仅仅将频率数值从 Hz 转换为 Mel，并没有得到 Mel 频谱。

- 本次曲线实验能够证明什么，不能证明什么：
能够展示 HTK 映射的非线性，以及等 Mel 间隔对应的 Hz 间距如何变化。但它不能单独证明某种 Mel 特征一定能够提高 ASR 模型性能，也不能代表已经实现 Mel 滤波器组或 Log-Mel 特征提取。


# W6D1 模块2：实现 hz_to_mel

## 1. 模块目标

实现的文件：
src/features.py
在原有音频特征处理代码基础上增加 hz_to_mel()，不覆盖已有 STFT 函数

函数输入：
单个Hz频率数值，或有多个Hz频率组成的数组

函数输出：
对应的Mel数值或Mel数组

为什么需要显式指定 scale：
因为 HTK 与 Slaney 使用不同的 Mel 频率映射约定，同一个 Hz 数值在两种约定下得到的 Mel 数值可能不同。
显式指定 scale 可以避免默认参数不一致造成错误比较。

## 2. HTK 实现

核心公式：
mel = 2595 × log10(1 + f/700)

NumPy 实现方法：
使用 np.asarray() 将输入转换为 NumPy 数组，再通过 np.log10() 对标量或数组执行转换。

为什么使用 np.log10：
因为 HTK 公式使用以10为底的对数。如果改用自然对数 np.log()，必须相应调整公式中的系数。

如何处理标量与数组：
np.asarray() 使函数能够接受标量、列表和数组。
对标量输入，使用 .item() 返回普通数值；对数组输入，返回相同形状的 Mel 数组。

## 3. Slaney 实现

1000 Hz 以下：
采用线性映射：
mel = f / (200/3)

1000 Hz 及以上：
采用对数映射：
mel = 15 + ln(f/1000) / [ln(6.4)/27]

为什么需要分段实现：
这是 librosa 中 Slaney Mel 尺度的定义约定，使用低频线性、高频对数的组合方式。两个分段在1000 Hz处具有相同的函数值，保证映射连续。

## 4. 测试与验证

测试的 Hz 数值：
[0, 100, 500, 1000, 2000, 8000]

HTK 对照方式：
将手写函数设置为 scale="htk"，与 librosa.hz_to_mel(hz, htk=True) 逐点比较。

Slaney 对照方式：
将手写函数设置为 scale="slaney"，与 librosa.hz_to_mel(hz, htk=False) 逐点比较。

实际最大误差：
- HTK：0.0
- Slaney：3.552713678800501e-15

异常输入如何处理：
代码通过 np.isfinite() 和非负值检查，拒绝负频率、NaN和Inf，并通过 ValueError 报告错误。对于不支持的 scale，也抛出 ValueError。

## 5. 代码衔接

features.py 的作用：
集中保存可复用的音频特征处理函数，包括已有STFT相关代码，以及新增加的Hz->Mel转换函数。

mel_basics.ipynb 的作用：
进行频率转换实验、绘制Mel曲线、调用手写函数，并于librosa进行数值对照

后续 Mel 滤波器组如何使用这个函数：
先将目标频率范围从Hz转换到Mel，在Mel尺度上确定滤波器位置，然后转回Hz，在FFT频率网格上计算滤波器权重。
后续通过滤波器组对STFT功率谱进行加权求和，得到Mel频带功率。

为什么此时还没有得到 Log-Mel 特征：
hz_to_mel 只负责频率坐标映射。
Log-Mel 特征还需要：
- 对波形进行 STFT。
- 计算幅度谱或功率谱。
- 使用 Mel 滤波器组汇总频谱信息。
- 对 Mel 特征进行对数压缩。

## 6. 当前理解

- HTK 与 Slaney 的主要区别：
HTK 使用整体对数形式，librosa 实现的 Slaney 尺度使用低频线性、高频对数的分段形式。

- 为什么比较时必须固定尺度定义：
只有使用相同的尺度约定，才能判断两份转换结果是否应该一致。

- 为什么 Mel 数值不同不一定代表计算错误：
不同尺度约定可以为同一 Hz 频率分配不同的 Mel 数值。只有在同一约定下进行比较，数值差异才可能表明实现错误。

- 为什么坐标映射函数应该与滤波器组构造分开：
坐标映射负责 Hz 和 Mel 的数值关系；滤波器组构造负责确定频带及其权重。分开实现可以提高代码复用性，方便单独测试不同 Mel 尺度，并在后续特征提取中明确滤波器组的配置。


# W6D1 模块3：Log 压缩与动态范围

## 1. 动态范围

什么是动态范围：
动态范围用于描述信号中较大数值与较小数值之间的差异，通常可以用比值或分贝表示。

为什么语音频谱中不同频带的功率可能相差很大：
语音具有非均匀的频谱结构，不同频带可能包含强弱不同的谐波、共振峰、噪声或其他声学成分，因此不同频带的功率可能相差多个数量级。

直接使用线性功率值可能带来什么问题：
当各频带功率相差很大时，强能量成分在数值和线性可视化中占据主要范围，弱能量成分不容易观察。在后续模型处理中，这种较大的数值跨度也可能使特征尺度不便于处理，因此通常会考虑对数变换和其他归一化方法。

## 2. Log 压缩

对数函数的基本特点：
对数函数单调递增，但其增长速度逐渐变慢

为什么对数可以压缩动态范围：
如果原始功率跨越多个数量级，对数变换能够将巨大的倍数差异表示为相对较小的数值差异。

功率相差10倍、100倍时，dB分别相差多少：
10、20

## 3. 数值稳定性

为什么不能直接对零取log：
log(0)在实数范围内没有有限值，对数函数在输入趋近于0的正方向时趋于负无穷。在NumPy中，直接计算可能产生-inf和运行警告；在后续计算中还可能引发NaN等数值问题。

eps或功率下限的作用：
power_safe = np.maximum(power, eps)保证对数函数的输入不低于一个严格大于0的下限。

为什么要记录所使用的对数定义和参考值：
不同实现可能使用自然对数、以10为底的对数或者dB表示。即使都使用dB，不同的参考值、功率下限或截断范围也可能导致数值不同。

## 4. Log-Mel处理流程

STFT的作用：
将原始时域语音转换为时频表示，反映不同时间帧、不同频率位置的频谱信息。

Mel滤波器组的作用：
利用Mel频率尺度确定多个滤波器的频率位置，通过加权求和将先行频率上的功率谱转换为Mel频带功率。
例如，第m个Mel频带的功率可以写为：
E(t, m) = Σ_f H(m, f) × P(t, f)
其中H(m, f)表示第m个Mel滤波器在频率f处的权重。

log变换的作用：
对Mel频带功率进行对数压缩，减小不同频带功率数值跨度，形成Log-Mel特征。

为什么hz_to_mel本身不是Log-Mel特征：
hz_to_mel只负责频率坐标转换。
完整的Log-Mel特征通常需要：
原始语音 → STFT → 功率谱 → Mel滤波器组 → Mel功率谱 → Log压缩。

## 5. 实验结果

测试的功率数值：
[1.0, 0.01, 0.0001, 0.0]

线性功率输出：
[1.0, 0.01, 0.0001, 0.0]

对数压缩后的输出：
使用eps=1e-10和10 × log10(P)，结果为：
[0.0, -20.0, -40.0, -100.0] dB

从实验中观察到的动态范围变化：
对于三个非零功率，原始数值从1变化到0.0001，跨越10000倍。
进行dB变换后，它们分别表示为0 dB、−20 dB和−40 dB。
对数变换将乘性比例关系转换为加性数值差异，便于显示和处理大范围的功率变化。

## 6. 当前理解

- Log压缩与Mel频率映射解决的问题有何不同：
Mel频率映射处理的是频率位置与频率尺度的关系，用于决定Mel滤波器组在频率轴上的分布。
Log压缩处理的是功率或幅度数值的动态范围。
Mel负责频率尺度，Log负责数值表示，两者作用不同。

- 为什么0功率需要特殊处理：
因为log(0)不是有限实数，直接计算会产生负无穷并可能导致后续数值问题。
实际处理时通常使用一个正数下限保证计算稳定。

- 为什么不能混淆自然对数与dB：
自然对数ln(P)与功率dB表达式10 × log10(P/P_ref)并不相同。

- 今天是否已经实现完整Log-Mel特征：
没有。
今天已经理解了Mel频率映射、实现了Hz到Mel的转换函数，并验证了Log压缩。
还没有完成Mel滤波器组对STFT功率谱的加权汇总，因此尚未形成完整的Log-Mel特征提取管线。
