# W6D2 模块1：STFT 功率谱与 Mel 滤波器组

## 1. 特征提取流程

从 waveform 到 Log-Mel 的主要步骤：
waveform -> STFT -> 功率谱 -> Mel滤波器组加权求和 -> Mel功率谱 -> Log压缩

STFT 的作用：
将一维时域语音转换为复数时频矩阵，描述信号在不同时间帧和不同频率位置上的频谱信息。

Mel 滤波器组的作用：
根据所选Mel尺度在频率轴上构造一组滤波器，对各时间帧的功率谱进行加权求和，将线性FFT频点汇总为Mel频带。

Log 的作用：
对Mel频带功率进行对数压缩，减小数值动态范围，同时保留不同频带之间的强弱关系。

## 2. 幅度谱与功率谱

STFT 的输出是什么：
复数矩阵D，包含幅度和相位信息。
其常见形状为 (F, T)，其中 F 表示频率点数，T 表示时间帧数。

幅度谱的计算：
A = abs(D)，表示每个时频点的复数模长。

功率谱的计算：
P = abs(D)²，表示每个时频点的平方幅度。本次使用这一形式，不额外将数值标定为以瓦特为单位的物理功率。

为什么本次实验要明确使用功率谱：
Mel滤波器组可以作用于幅度谱或功率谱，但两者数值不同，必须明确输入形式，才能保证手写流程与库函数的对照具有可比性。

## 3. Mel 滤波器组

滤波器组矩阵的含义：
Mel滤波器组矩阵W的每一行代表一个Mel滤波器，每一列对应一个FFT频率点。
矩阵元素W[m,k]表示第m个Mel滤波器对第k个频率点的权重
实际常用的是相互重叠的三角滤波器

n_mels 的含义：
Mel 滤波器的数量，也就是输出 Mel 频带的数量。

单个 Mel 频带的功率如何计算：
E[m, t] = Σ_k W[m, k] × P[k, t]
其中 P[k, t] 是时间帧 t 在频率点 k 上的功率。

为什么 Mel 滤波器组不只是改变频率轴的标签：
因为它真正执行了数值加权汇总，将多个 FFT 频率点的信息映射到新的 Mel 频带。
单独使用 hz_to_mel 只改变频率坐标数值，不会完成这一加权运算。

## 4. 矩阵形状

STFT 矩阵形状：
(F, T)，其中 F = floor(n_fft / 2) + 1。

功率谱矩阵形状：
(F, T)，与 STFT 相同。

Mel 滤波器组矩阵形状：
(M, F)，其中 M=n_mels。

Mel 功率谱矩阵形状：
(M, T)。

为什么可以进行矩阵乘法：
W 的列数 F 与 P 的行数 F 相同，满足矩阵乘法条件。
从信号处理角度看，是对每个时间帧的 F 个频率点分别执行 M 组加权求和。

## 5. 实验配置

sample_rate：32000 Hz

n_fft：1024

win_length：800采样点，即25 ms

hop_length：160采样点，即5 ms

window：Hann

center / pad_mode：True/ constant，即边界补零

power：使用 abs(STFT)²

n_mels：80

fmin / fmax：0 Hz/16000 Hz

htk / norm：使用 Slaney Mel 尺度/使用 Slaney 面积归一化

log 底数、系数与 eps：10 × log10(P / P_ref)/1/1e-10，对数输入下限

## 6. Whisper 的区别

本次教学特征与 Whisper 完整前处理是否等价：
不等价，
本次教学配置使用32kHz采样率、1024点FFT、800点窗长、160点帧移和自定义的dB输出规则。
官方Whisper前处理使用16kHz采样率、400点FFT、160点帧移、Hann窗，以及特定的帧处理、对数截断和数值缩放流程。

为什么即使都叫 Log-Mel，也需要对齐参数：
Log-Mel 是一类特征的名称，不代表所有实现完全一致。
采样率、FFT点数、窗长、帧移、窗函数、边界处理、Mel尺度、滤波器归一化、功率指数、log底数和缩放规则都可能影响最终特征。
因此，不能仅凭 n_mels=80，就将本次教学特征视为可直接用于 Whisper 的完整输入。

## 7. 当前理解

- 为什么需要先计算 STFT 再应用 Mel 滤波器组：
Mel滤波器组操作的对象是频谱信息。STFT先将时域波形转换为频谱，再由滤波器组按 Mel 频带对频谱进行加权汇总。

- 幅度谱与功率谱有什么区别：
幅度谱是复数STFT系数的模长，即 abs(D)。
本次功率谱是幅度谱的平方，即 abs(D)²。

- Mel 滤波器组怎样把 F 个频率点变成 M 个频带：
使用形状为 (M, F) 的滤波器组矩阵，与形状为 (F, T) 的功率谱矩阵相乘，输出形状为 (M, T)。每一行滤波器权重对应一次对 F 个频率点的加权求和。

- 为什么不能把本次输出直接称为 Whisper 输入特征：
因为本次教学特征和官方 Whisper 的前处理配置与后处理规则不同。特征的名称、维度相似，并不意味着数值或模型接口完全一致。


# W6D2 模块2：实现 waveform_to_mel

## 1. 函数设计

文件位置：src/features.py

输入 waveform 的形状：
一维单声道波形，形状为 (N,)，其中 N 为采样点数。

输入采样率：
通过 sr 参数显式传入，必须与波形的实际采样率一致。

输出特征的形状：
(n_mels, n_frames)

为什么要明确要求单声道：
本函数按照一维波形设计。如果直接传入多通道数据，可能导致维度不符合预期或产生歧义。

## 2. 功率 STFT

STFT 使用的库函数：
librosa.stft()

窗函数及相关参数：
- sample_rate = 32000 Hz
- n_fft = 1024
- win_length = 800
- hop_length = 160
- window = "hann"
- center = True
- pad_mode = "constant"

幅度谱如何得到：
magnitude = np.abs(D)

功率谱如何得到：
power_spec = np.abs(D) ** 2

## 3. Mel 滤波器组

使用的库接口：
librosa.filters.mel()

htk / norm 配置：
- htk = False：使用Slaney Mel尺度。
- norm = "slaney"：采用Slaney面积归一化。

滤波器组矩阵的形状：
(n_mels, n_fft // 2 + 1)

矩阵乘法的作用：
mel_power = mel_filter @ power_spec
对每个时间帧的513个频率点进行80组加权求和，将频率维度从513变为80，时间帧数保持不变。

## 4. Log 处理

使用的对数底数：
10

使用的功率参考值：
1.0

eps 的作用：
通过 np.maximum(mel_power, eps) 为对数输入设置正数下限，避免零功率产生负无穷。

是否使用 top_db 截断：
没有

## 5. 验证结果

测试信号：
- 440 Hz正弦波
- 采样率：32000 Hz
- 时长：1秒
- 采样点数：32000
- 幅值：0.2

waveform_to_mel 输出形状：
(n_mels,T)

库函数对照方式：
使用相同参数调用 librosa.feature.melspectrogram()，显式指定 power=2.0，再执行与自定义函数相同的Log变换。

最大绝对误差：
0.0

零信号测试：
输入全零波形后，输出为有限值；由于eps为1e-10，所有输出均为−100 dB。

## 6. 工程注意事项

为什么函数不自动重采样：
特征提取与采样率转换属于不同的处理步骤。

为什么要检查输入数值：
空数组、错误维度、NaN、Inf以及不合理的参数可能造成计算错误或无效特征。

为什么不同配置不能直接比较：
采样率、n_fft、win_length、hop_length、窗函数、边界处理、Mel尺度、滤波器归一化、功率指数及Log规则都会影响特征数值。

为什么本函数不是 Whisper 的完整前处理：
本函数是使用librosa实现的教学班Log-Mel功率谱，
Whisper官方实现使用不同的采样率、FFT配置和时间帧处理，还包含特定的Log截断、缩放与模型输入长度处理。因此，本函数不等价于Whisper官方的processor

## 7. 当前理解

- waveform_to_mel 内部各步骤的职责：
STFT负责计算时频表示；功率谱计算平方幅度；Mel滤波器组负责频带加权汇总；Log负责压缩数值动态范围

- 功率谱与 Mel 功率谱的关系：
Mel功率谱是对线性FFT功率谱使用滤波器组进行加权求和后的结果，频率维度由FFT频点数变为Mel频带数

- Log 变换是否改变矩阵形状：
不会

- 如何判断实现与库函数一致：
首先明确相同的输入和参数，然后比较输出形状、数值最大绝对误差、并使用np.allclose()验证。

## 5. 当前理解

- 为什么两张图展示的是同一段语音：
两张图使用相同的waveform作为输入。
STFT功率谱展示线性频率上的视频信息；Log-Mel是进一步通过Mel滤波器组与Log变化得到的另一种特征表示。
因此，两张图描述的是同一段语音的不同频谱表示。

- 为什么Mel频谱不能仅理解为重新标注频率坐标：
因为Mel滤波器组实际执行了加权求和，将多个FFT频率点的信息汇总到对应的Mel频带。它不只是将频率刻度从Hz转换为Mel。

- 为什么两张图的颜色值不一定可以直接逐点比较：
STFT功率谱对应单个FFT频率点的平方幅度。
Mel功率谱对应滤波器组对多个频率点的加权汇总结果，并受到滤波器归一化影响。

- 为什么保存特征配置与保存代码同样重要：
相同代码在不同参数下可能生成不同特征。
只有明确记录采样率、STFT参数、窗函数、Mel尺度、滤波器归一化、功率指数与Log规则，才能准确复现实验并比较结果

- 为什么本次结果不等于Whisper官方特征：
本次使用的是教学班Log-Mel功率谱
它采用32000Hz采样率、1024点FFT、800点窗长等配置，并执行10 × log10的功率dB变换。
Whisper官方前处理使用不同的采样率与STFT配置，还包含特定的时间帧处理、对数截断和缩放规则。
因此，本次实验用于理解特征提取及后续数据管线，不直接冒充Whisper的完整前处理。
