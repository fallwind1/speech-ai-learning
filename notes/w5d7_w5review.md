# W5D7 模块1：STFT 概念复盘

## 1. STFT的基本流程

STFT如何处理整段语音：
将语音分成许多相互重叠的短帧，对每一帧加窗并计算FFT。

为什么需要分帧：
分帧的目的是观察语音在不同时间段的频率结构。真实语音是非平稳信号，整段FFT只能展示总体频率成分，不能直接说明这些成分分别在什么时间出现。

为什么需要加窗：
加窗是为了减弱有限长度截断导致的频谱泄漏。常见的Hann窗会降低旁瓣，但相较矩形窗，其主瓣通常更宽，因此窗函数的选择也涉及频谱泄漏和频率分辨能力之间的权衡。

## 2. win_length

参数定义：
win_length表示每帧实际使用的窗口长度，单位为采样点。

实际观测时长的计算公式：
T_win = win_length / sample_rate

增大win_length对时间定位能力的影响：
每帧观察的时间范围变长，短暂变化可能被平均到更长的窗口中，因此时间定位能力通常下降。

增大win_length对频率分辨能力的影响：
较长的真实观测时长通常使窗口频谱主瓣变窄，有利于区分相近频率。

## 3. hop_length

参数定义：
hop_length表示相邻帧起点之间的采样点数。

相邻帧起点间隔的计算公式：
T_hop = hop_length / sample_rate

减小hop_length对帧数的影响：
帧与帧之间的间隔变小，同一段音频会被分析得更密集，因此通常会产生更多时间帧，计算量也会增加。

减小hop_length是否提高单帧近频分辨能力：
不会直接提高。

## 4. n_fft

参数定义：
n_fft表示每帧FFT的计算点数。

频率网格间距公式：
Δf = sample_rate / n_fft

n_fft大于win_length时如何处理：
窗口信号需要补零到n_fft所要求的长度，再执行FFT。补零增加了频率网格的采样密度，但没有增加真实观测时长。

补零能否提高真实近频分辨能力：
单纯补零不能提高真实的近频分辨能力。需要区分频率网格更密和真实区分两个近频成分的能力更强。

## 6. 当前理解

- win_length与hop_length最关键的区别：
win_length决定每帧观察多长的信号，hop_length决定相邻起点相隔多远

- 为什么窗长会影响时频权衡：
较长的真实观测时长通常有利于频率分辨，但会降低时间定为能力；较短的窗口则相反。

- 为什么帧移减小不等于频率分辨能力提高：
帧移只改变时间采样密度，不改变每帧的真实观测时长。

补零只增加FFTT计算点数和频率网络的采样密度，不会产生新的真实语音观测数据。

## 3. 本周掌握的关键概念

### 3.1 短时平稳假设

真实语音是非平稳信号，但在足够短的时间片段内，可以近似认为信号特性变化较小。因此可以分帧分析每一帧的频率结构。

### 3.2 窗长与频率分辨能力

win_length 决定每帧的真实观测时长。窗长增加通常有利于区分相近频率，但会降低时间定位能力。

### 3.3 帧移与时间采样密度

hop_length 决定相邻帧起点之间的距离。帧移越小，时间采样越密集，帧数通常越多，但不会直接提高单帧的近频分辨能力。

### 3.4 补零与频率网格

n_fft 决定 FFT 的计算点数和频率网格间距。补零可以使频率网格更密，但不会增加真实观测时长，也不能单靠补零提高实际近频分辨能力。

### 3.5 目标 SNR 与实测 SNR

target_snr_db 是实验设定值，measured_snr_db 是实际测量值。两者需要分别记录，不能将目标值直接当作实验结果。

### 3.6 parent_uid 与实验复现

parent_uid 用于追踪原始音频来源。condition、seed、target_snr_db 和 output_path 等字段用于描述派生样本的实验条件和保存位置。
