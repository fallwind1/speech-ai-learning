## 3. 来源与时间段检查

source_id：
- 两组使用相同的 Common Voice 语料来源标识。
- source_id 表示语料来源，不作为样本隔离标识。

时间段：
- Common Voice 每条 clip 是独立音频。
- start_time 从 0 开始。
- end_time 对应当前 clip 的音频长度。
- 不存在需要跨 clip 比较的共享原始录音时间轴。
- 时间段交叠检查不适用。

Session：
- Test 存在 session_uid 字段。
- Dev Manifest 不包含 session_uid。
- Session 级别隔离无法独立验证。
