# W3D4 模块1：LayerNorm 原理与归一化维度

## 1.1 LayerNorm解决什么问题

LayerNorm的基本作用：

> 通过每个被归一化单元内部的均值和方差来标准化特征，再使用可学习参数恢复所需的表达能力

为什么神经网络中需要Normalization：

> 深层网络中不同层、不同位置的隐藏表示可能存在较大的数值尺度差异。Normalization可以调整这些表示的分布与尺度，有助于改善训练时的数值表现和优化条件。

---

## 1.2 LayerNorm归一化哪些维度

假设Transformer隐藏表示：

```text
X shape = (B,T,d)
```

其中：

```text
B = 2
T = 3
d = 4
```

如果使用：

```python
nn.LayerNorm(d)
```

则均值和方差沿着：

> 每个token的特征进行

是否跨Batch归一化：

> 不跨

是否跨序列位置归一化：

> 不跨

---

## 1.3 LayerNorm数学公式

均值：

\[
\mu =\frac1d\sum_{i=1}^{d}x_i
\]

方差：

\[
\sigma^2 =\frac1d\sum_{i=1}^{d}(x_i-\mu)^2
\]

归一化：

\[
\hat{x}_i =\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}
\]

最终输出：

\[
y_i =\gamma_i\hat{x}_i+\beta_i
\]

---

## 1.4 eps、gamma与beta

eps作用：

> 防止方差非常小甚至为0时分母变成0

gamma作用：

> 可学习的缩放参数，控制归一化后每个特征的尺度。

beta作用：

> 可学习的平移参数，控制归一化后每个特征的偏移

其中可学习参数：

> 默认初始化gamma=1，beta=0

---

## 1.5 Transformer中的LayerNorm

输入：

```text
X = (B,T,d)
```

执行：

```python
layer_norm = nn.LayerNorm(d)
Y = layer_norm(X)
```

输出shape：

> (B,T,d)

每个位置的归一化统计量来自：

> 当前位置的d个特征，而不是其他token或其他batch样本。

---

## 1.6 手写实现要注意什么

均值计算：

```python
mean = x.mean(dim=-1,keepdim=True)
```

方差计算：

```python
var = x.var(dim=-1,keepdim=True,unbiased=False)
```

归一化：

```python
x_hat = (x-mean)/torch.sqrt(var+eps)
```

与PyTorch对照时需要注意：

> 归一化维度、方差定义、eps以及gamma/beta必须一致。

---

## 1.7 理解检查

① LayerNorm主要解决什么问题？
LayerNorm调整隐藏表示的数值尺度，帮助深层网络中的计算和优化保持在更易处理的范围内。

② 对于 `(B,T,d)`，`nn.LayerNorm(d)` 沿哪个维度归一化？
沿最后的64个特征计算均值和方差，每个token独立处理，共160组均值和160组方差。

③ 为什么不直接跨Batch计算均值和方差？
不会。因为LayerNorm(d)不跨token或batch计算统计量，其他token的输入保持不变，其归一化结果也不变。

④ eps为什么放在根号内？
eps加入方差后一起开根号，保证方差较小时分母仍然为正，并改善数值稳定性。这是LayerNorm公式的定义，不等同于在标准差后加eps。

⑤ gamma和beta有什么作用？
gamma负责缩放，beta负责平移。它们使网络能在归一化后继续学习适合任务的特征尺度和偏移量。

⑥ LayerNorm会改变Tensor的shape吗？
不会

⑦ 为什么计算方差时需要注意 `unbiased=False`？
因为nn.LayerNorm使用分母为d的总体方差，unbiased=False可以保证手写方差与库实现采用一致的定义，避免因方差计算方式不同产生输出差异。

---

## 1.8 核心结论

> Transformer中常用的nn.LayerNorm(d)沿每个token的最后d个特征独立计算均值和总体方差，经过标准化后再使用可学习的gamma、beta进行缩放和平移。它不改变Tensor shape，也不跨batch或token计算统计量。

```text

↓

↓

↓
输出y
```

---

## 2.2 初始化参数

```python
gamma = nn.Parameter(torch.ones(d))

beta = nn.Parameter(torch.zeros(d))
```

为什么使用`nn.Parameter`：

> 因为普通Tensor不一定被模型自动注册为可学习参数，而nn.Parameter赋值到nn.Module属性时，被注册为模型参数。

---

## 2.3 计算均值和方差

```python
mean = x.mean(dim=-1, keepdim=True)

var = x.var(
    dim=-1,
    keepdim=True,
    unbiased=False,
)
```

为什么使用`dim=-1`：

> 对最后一维特征维度进行计算

为什么使用`keepdim=True`：

> 便于后续矩阵运算

---

## 2.4 归一化与仿射变换

```python
x_hat = (x-mean) / torch.sqrt(var + self.eps)

output = self.gamma * x_norm + self.beta
```

---

## 2.5 与PyTorch对照

库实现：

```python
reference = nn.LayerNorm(
    d
)
```

对照时必须一致的条件：

> 相同的输入x、初始可学习参数、eps

---

## 2.6 误差与验证

最大绝对误差：

```python
max_error = (manual_output - reference_output).abs().max()
```

近似相等：

```python
is_close = torch.allclose(
    manual_output,
    reference_output,
    atol=1e-6,
    rtol=1e-5
)
```

为什么不直接使用`==`：

> 因为浮点运算可能存在微笑舍入误差，不要求所有元素均严格相等

---


---

## 2.8 核心结论

> 手写LayerNorm的关键是沿指定特征维度计算均值和总体方差，将输入标准化再应用可学习的gamma和beta。与nn.LayerNorm对照时，必须保持输入、归一化维度、eps和仿射参数一致，再通过最大绝对误差与torch.allclose验证数值准确性。


# W3D4 模块3：Residual Connection与Pre-LN/Post-LN

## 3.1 Residual Connection

普通子层：

```text
x
↓
F(x)
↓
output
```

残差连接：

\[
y=x+F(x)
\]

其中：

> x代表：当前子层的输入隐藏表示

> F(x)代表：当前子层对输入进行Attention、FFN等变换后得到的新表示

为什么能够相加：

> 通常要求x和F(x)具有相同shape，能够逐元素相加，并保持隐藏表示维度不变。

## 3.3 Pre-LN

结构：

```text
x
↓
LN
↓
F(LN(x))
↓
x+F(LN(x))
```

数学形式：

\[
y=x+F(LN(x))
\]

---

## 3.4 Post-LN

结构：

```text
x
↓
F(x)
↓
x+F(x)
↓
LN(x+F(x))
```

数学形式：

\[
y=LN(x+F(x))
\]

---

## 3.5 Pre-LN与Post-LN的主要区别

Pre-LN中LayerNorm位于：

> 子层F之前，放在需要学习的变化分支内部

Post-LN中LayerNorm位于：

> 残差相加之后

R03原始Transformer使用：

> Post-LN

从梯度传播路径看：

> Pre-LN：残差分支中的x可以绕过LayerNorm和F，直接到达相加节点，因此在整个block中保留了直接的恒等梯度路径。
> Post-LN：残差分支虽然绕过了F，但梯度从block输出返回时仍需要经过最后的LayerNorm，因此整个block的梯度传递并非简单的恒等映射。

---

## 3.6 理解检查

① 为什么残差分支要求x和F(x)具有兼容的shape？
因为需要计算x+F(x)。Transformer中通常让二者保持相同shape，从而逐元素相加并维持隐藏表示维度。

② 若y=x+x²，x=2，dy/dx是多少？其中残差分支贡献多少？
残差分支贡献 = 1
F(x)分支贡献 = 4

③ 残差连接是否能保证深层网络完全没有梯度消失？为什么？
因为最终梯度由不同分支的贡献相加，可能发生抵消；此外实际网络还有归一化、复杂子层和多层梯度传播。残差只是增加了直接路径，并不保证最终梯度一定非零或训练一定稳定。

④ 写出Pre-LN的数据流和公式。
x → LayerNorm → F → Add(x) → y

⑤ 写出Post-LN的数据流和公式。
x → F → Add(x) → LayerNorm → y

⑥ R03原始Transformer采用哪一种？
Post-LN。

⑦ 为什么Pre-LN通常有利于梯度沿残差路径传播？
因为LayerNorm位于F分支内部，残差输入x能够绕过LayerNorm和F直接到达相加节点，从而在整个block中保留直接的恒等梯度路径。

---

## 3.7 核心结论

> Residual Connection通过y=x+F(x)提供绕过复杂子层的直接信息和梯度路径。Pre-LN采用x+F(LN(x))，使残差分支保留直接的恒等路径；Post-LN采用LN(x+F(x))，其梯度需要经过输出端LayerNorm。Pre-LN通常更有利于深层模型优化，但不能保证没有梯度问题，也不代表训练一定不需要warmup。


# W3D4 模块4：Pre-LN、Learning Rate Warmup与最终验收

## 4.1 Learning Rate Warmup

Warmup的含义：

> 在训练初期使用较小的学习率，随后逐渐增加到预设目标学习率，以降低早期参数更新过于激进的风险。

典型学习率变化：

```text
训练开始
↓
使用较小学习率
↓
达到目标学习率
↓
根据学习率调度策略继续训练
```

---

## 4.2 为什么需要Warmup

训练初期可能存在的问题：

> 模型参数尚未形成适合当前任务的表示，梯度与参数更新可能比较敏感。如果一开始采用较大的学习率，可能导致参数更新过于激进，造成loss震荡、数值不稳定等问题。

Warmup的主要作用：

> 逐渐提高学习率，控制训练初期的参数更新幅度，降低过大更新带来的不稳定风险。

---

## 4.3 Pre-LN与Warmup的关系

Pre-LN改善的主要方面：

> 通过将LayerNorm放入子层F分支内部，使残差路径绕过LayerNorm和F，保留更直接的恒等梯度传播路径，通常有利于深层模型优化。

Warmup控制的主要方面：

> 训练初期的学习率变化，以及由此影响的参数更新幅度。

为什么Pre-LN不代表不需要Warmup：

> 因为Pre-LN属于模型架构设计，Warmup属于训练策略。改善梯度传播路径并不等于所有训练配置下的参数更新都会稳定。

---

## 4.4 Pre-LN/Post-LN与Warmup的区别

| 项目 | 作用 |
|---|---|
| Pre-LN |在F之前执行LayerNorm，保留更直接的恒等残差梯度路径，属于模型结构设计|
| Post-LN |在残差相加之后执行LayerNorm，整个block的梯度需要经过输出端LN，属于模型结构设计|
| Warmup |在训练初期逐步提高学习率，控制初期参数更新幅度，属于训练策略|

## 4.6 理解检查

① 什么是learning rate warmup？
Warmup是在训练初期从较小学习率逐渐增加到目标学习率的过程，以降低早期参数更新过于激进的风险。达到目标学习率之后还可以继续使用其他调度策略。

② 为什么模型训练初期可能需要较小的学习率？
因为训练初期的参数和优化状态可能比较敏感，较大的学习率可能造成参数更新过大，导致loss震荡或训练不稳定。

③ 为什么Pre-LN一般更有利于梯度传播，却不能直接推出不需要warmup？
Pre-LN改善的是模型结构的梯度传播路径，Warmup控制的是训练初期学习率和参数更新幅度。改善梯度传播条件不代表模型在所有学习率配置下都可以稳定训练。

④ Pre-LN和Warmup分别属于模型结构还是训练策略？
第一个是模型结构，LayerNorm位于F分支之前，残差分支保留原始x
第二个是训练策略，学习率调度的一部分

⑤ 用一句话解释Pre-LN、Post-LN和Warmup三者的关系。
Pre-LN和Post-LN规定Transformer block内部归一化与残差连接的组织方式，Warmup控制训练初期学习率的变化。三者作用于不同层面，采用Pre-LN并不意味着一定可以省略Warmup。

---

## 4.7 本日核心结论

> LayerNorm通常沿Transformer隐藏表示的最后一个特征维度独立归一化；残差连接通过x+F(x)提供直接信息与梯度路径；Pre-LN将LayerNorm置于F之前，而Post-LN将其置于残差相加之后。Pre-LN通常有利于梯度传播，但不能替代学习率Warmup等训练策略。
